# Tidepool assets

## Music

- `music/tidepool_background.mp3` — original composition by the Tidepool author,
  © InauguralSystems. Released under this repository's MIT license (see
  [../LICENSE](../LICENSE)); you may reuse it under those terms.

The game degrades gracefully if this file is missing (no music, no crash), and
background music additionally requires EigenScript's `audio_music_*` builtins
(v0.18.0+) and `libsdl2-mixer-2.0-0` at runtime.
